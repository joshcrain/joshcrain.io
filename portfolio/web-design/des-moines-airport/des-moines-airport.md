**Role:** Web Designer & Front-End Developer
**Tools:** HTML, CSS, JS/jQuery, Common Patterns Design System
**Scope:** Design & front-end development, API integration, handoff for CMS implementation

An airport website is a high-stakes information environment. Travelers are making time-sensitive decisions — flight status, parking, wayfinding — often under pressure. The goal was to answer those questions clearly while giving the airport’s team a CMS they could maintain without design support.

Before designing anything, I audited peer airports to understand established UX patterns for different traveler types, and explored the capabilities of flight and weather APIs early. Understanding what the data could and couldn’t do shaped interface decisions before they were locked in — a better order of operations than designing first and discovering constraints later.

Design began with low-fidelity mockups, moving to high-fidelity prototypes and in-browser builds as the work refined. I worked closely with developers to assess API feasibility and integrate real-time flight and weather data in a way that was visually clear — custom iconography layered over API data rather than raw feeds. Navigation and featured content priorities shifted mid-project as real content needs emerged from stakeholder reviews, which is normal and worth building for.

Front-end development used semantic HTML, modular CSS, and jQuery, built on **Common Patterns** for a consistent accessibility and responsiveness baseline. The finished front-end was handed off to backend developers for CMS integration.

The site received an Addy Award.
